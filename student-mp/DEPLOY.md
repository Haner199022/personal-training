## A. 本地预览（现在可做，无需 AppID）

1. **启动后端**（已验证可跑）
   ```bash
   cd ~/code/personal-training/backend
   ./run-dev.sh        # 持久化启动（8001，后台 nohup）；停止：./run-dev.sh stop
   # 或手动：.venv/bin/uvicorn app.main:app --port 8001
   # → http://127.0.0.1:8001/api/v1/health
   ```
   > ⚠️ 用 **8001**，不要用 8000——本机 8000 被 AI Team OS API 占用，撞端口会导致后端时好时坏。
   > dev 用本地 SQLite 种子库（`.env` 的 `DATABASE_URL=sqlite+aiosqlite:///./dev.db`），不要指向未搭建的 PostgreSQL。
2. **装「微信开发者工具」**（macOS）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   - 这是 GUI 程序，必须你本人装 + 操作，命令行无法代替。
3. **导入项目**：开发者工具 → 导入 → 选 `~/code/personal-training/student-mp/`
   - 没有 AppID 时点「测试号」或「无 AppID」即可进模拟器。
4. **构建 npm**：工具 → 构建 npm（生成 `miniprogram_npm/`，weui 组件需要）。
5. **关掉域名校验**：详情 → 本地设置 → 勾「不校验合法域名…」（这样模拟器能连本地 8000 后端）。
6. 模拟器里就能看到学员端全流程：登录 → 加入教练 → 今日训练 → 打卡 → 体脂趋势 → 消息 → 我。

> 真机预览（手机扫码）需要真实 AppID（走 B 流程拿到后才行）；模拟器不需要。

## B. 正式上线 · 关键路径（人工步骤为主）

```
①公司营业执照 ──→ ②域名注册 ──→ ③小程序账号→AppID ──→ ④ICP备案+小程序备案 ──→ ⑤后端部署 ──→ ⑥提审发布
  2-3周·你做       你做           企业主体·你做         7-14天·线下核验·你做      我可全包       你点按钮·我做合规自查
```
> 真正瓶颈是 **①公司注册还没启动**——它不完成，AppID 拿不到，小程序上不了真机/线上。

### 阶段 ① 注册有限公司（营业执照）— 你做 · 2-3 周
- 依据 `adr/0013-corporate-entity-not-individual`：必须有限公司（不走个体户，为将来 EDI 经营许可证铺路）。
- 品牌名（练程 / 练+ 等）作为字号提交核名（见 `plan/naming-candidates-2026-05-22`）。

### 阶段 ② 注册域名 — 你做
- `.com` + `.cn` 都注册；实名认证（约 5 工作日）。
- W0 先以个人名义注册，公司下来后过户到公司（`plan/w0-user-actions` ④⑥）。

### 阶段 ③ 注册小程序账号 → 拿 AppID — 你做（关键安全点）
1. 用**一个全新邮箱**（从未注册过任何微信产品）在 https://mp.weixin.qq.com 注册，主体选「企业」。
2. 做微信认证（¥300/年，1-3 天，推荐）。
3. 开发管理 → 拿到 **AppID**（非敏感，可以直接发我）+ 生成 **AppSecret**。
   - ⚠️ **AppSecret 关弹窗后再也看不到**：先存本地记事本；**永远不要贴进任何聊天/邮件/网盘**。
4. 把 AppID 填进 `student-mp/project.config.json` 的 `appid`（目前是占位 `TOUCH_ME_REPLACE_WITH_REAL_APPID`）。
5. AppSecret 我会教你用 `read -s` 静默写进后端 `.env`（不回显、不入 git）。

### 阶段 ④ ICP 备案 + 小程序备案（并行）— 你做 · 7-14 天
- **两套独立流程，W1 第一天就并行提交**，别串行等（`research/regulatory-checklist`）。
- ICP 主体备案：营业执照 + 法人身份证 + 域名证书 + 网站负责人线下核验拍照（上海/北京/广州指定点）。
- 小程序备案：类目选「健身」；备注训练计划 + 体脂趋势。
- ⚠️ **ICP 备案号下发 30 日内必须做公安备案**（不是上线后）。
- 拒因 Top1：**类目与功能不符**——提审前所有功能必须真实可用（这就是为什么先把页面补全）。

### 阶段 ⑤ 后端部署到备案 HTTPS 域名 — 我可全包
- 已备好 `deploy/`（docker-compose + nginx + Dockerfile + certbot 指南）。
- 域名 ICP 通过后：腾讯云轻量 4C8G → `docker compose up -d` → certbot 出证 → HTTPS 生效。
- 把 `https://api.<域名>` 填进 `student-mp` 生产配置，并在微信公众平台「开发设置 → 服务器域名 request 合法域名」加入白名单。

### 阶段 ⑥ 提交审核 → 发布 — 你点按钮，我做合规自查
1. 微信开发者工具 → 上传代码（填版本号）。
2. 公众平台 → 提交审核（首次较慢）。我会在提审前自查：类目/文案/截图无医疗减肥词、功能完整、隐私协议齐。
3. 审核通过 → 发布。先发**体验版**给你 + 3-5 个学员内测，再正式发布。
